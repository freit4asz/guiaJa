GUIAJA - PROJETO COMPLETO (site + servidor + banco)

PASSO 1 - Banco de dados (MySQL Workbench)
  File > Open SQL Script > banco/guiaja_banco.sql > clique no raio.

PASSO 2 - Senha do MySQL
  Copie .env.example para .env e preencha MYSQL_PASSWORD com a senha do MySQL.
  Não compartilhe nem publique o arquivo .env.

PASSO 3 - Terminal do VS Code (Terminal > New Terminal), dentro desta pasta:
  node -v          (confere se o Node.js está instalado)
  npm install      (instala as dependências, só na primeira vez)
  npm start        (liga o servidor)

PASSO 4 - Abra no navegador:  http://localhost:3000
  Login de teste: ana@email.com / Senha@123
  (para parar o servidor: Ctrl + C no terminal)

PUBLICAÇÃO NA VERCEL
  1. Hospede o MySQL em um serviço externo que aceite conexoes da Vercel.
  2. Importe banco/guiaja_banco.sql em um banco novo ou aplique as
     migracoes indicadas no README.md em um banco existente.
  3. Importe este repositorio na Vercel com a raiz do projeto como diretorio.
  4. Em Settings > Environment Variables, configure MYSQL_HOST,
     MYSQL_PORT, MYSQL_USER, MYSQL_PASSWORD, MYSQL_DATABASE e MYSQL_SSL.
     Use MYSQL_SSL=true se o provedor exigir TLS. Nunca publique senhas no Git.
  5. Faca o deploy e teste o site e uma rota /api.

  O build da Vercel instala as dependencias do servidor e do Angular,
  compila a interface e publica site e API no mesmo dominio. Sem MySQL
  remoto e as variaveis acima, as paginas podem abrir, mas as operacoes
  de dados falharao.

  O worker de e-mail atual depende de um processo Node.js continuo e nao
  e iniciado pelas funcoes serverless da Vercel. Para enviar notificacoes,
  hospede o worker em um servico com processo continuo ou configure um
  agendador compativel. Cadastre segredos SMTP como variaveis de ambiente,
  nunca no repositorio.
