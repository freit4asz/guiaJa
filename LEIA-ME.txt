GUIAJA - PROJETO COMPLETO (site + servidor + banco)

PASSO 1 - Banco de dados (MySQL Workbench)
  File > Open SQL Script > banco/guiaja_banco.sql > clique no raio.

PASSO 2 - Senha do MySQL
  Abra server.js e troque SUA_SENHA_DO_MYSQL pela senha do seu MySQL.

PASSO 3 - Terminal do VS Code (Terminal > New Terminal), dentro desta pasta:
  node -v          (confere se o Node.js está instalado)
  npm install      (instala as dependências, só na primeira vez)
  npm start        (liga o servidor)

PASSO 4 - Abra no navegador:  http://localhost:3000

  (para parar o servidor: Ctrl + C no terminal)

PUBLICAÇÃO NO RENDER
1. Crie um banco MySQL externo (por exemplo, Aiven ou PlanetScale).
2. Importe o conteúdo de banco/guiaja_banco.sql no banco externo.
   Ajuste o script para não executar DROP DATABASE nem CREATE DATABASE em um banco gerenciado.
3. No GitHub, envie este projeto para o repositório.
4. No Render, crie um novo Web Service conectado ao repositório.
5. Use Runtime: Node, Build Command: npm install e Start Command: npm start.
6. Cadastre estas Environment Variables no Render:
   MYSQL_HOST = endereço do banco
   MYSQL_PORT = porta do banco
   MYSQL_DATABASE = nome do banco
   MYSQL_USER = usuário do banco
   MYSQL_PASSWORD = senha do banco
   MYSQL_SSL = true (quando o provedor exigir)
   Alternativamente, cadastre MYSQL_URL com a URL mysql:// fornecida pelo provedor.
